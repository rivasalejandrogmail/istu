## Controles del proyecto

`npm run build` comprueba la sintaxis del JavaScript, presencia de recursos locales, unicidad de IDs y destino de anclas internas. Sin dependencias de ejecución ni paso de compilación requerido para publicar.

La revisión no incluye acceso autenticado al campus, llamadas telefónicas ni confirmación de apertura actual de carreras y cursos. No hay integración con un sistema institucional de inscripciones. Las consultas preparadas no se envían.
